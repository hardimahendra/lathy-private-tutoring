# Lathy Private — Next.js

**Live demo:** https://lathy-private.vercel.app

Modernisasi frontend landing page les privat dari proyek React lama lathy-private/client (proyek lama).

- Jalankan: `npm install` lalu `npm run dev`.
- Endpoint demo: `GET /api/program`.
- Form konsultasi hanya menampilkan konfirmasi lokal dan tidak menyimpan atau mengirim data.
